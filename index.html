🚫
As funções de IA não funcionarão neste modo

Você abriu o app direto pelo arquivo (protocolo file://). O navegador bloqueia as chamadas às APIs de IA nesse modo por segurança.

Como resolver — 3 passos:

  1. Feche esta aba do navegador.
  2. Na pasta do app, dê duplo clique em iniciar.bat (não no index.html).
  3. Espere 2-3 segundos. Uma janela preta vai abrir e o navegador vai abrir sozinho. Use o app a partir dele.

Se o navegador não abrir sozinho, copie o endereço abaixo e cole no navegador:
http://localhost:8000

Mais detalhes: abra o arquivo INICIAR-LEIA-ME.txt na mesma pasta.

⚙️ Configurar chaves de API

Cole suas chaves de API abaixo. O app tentará os provedores na ordem: primário → outros. As chaves ficam apenas no seu navegador (memória da sessão) e somem ao fechar a aba.

Como obter as chaves (todas gratuitas, sem cartão):
  1. Gemini (recomendado): aistudio.google.com/app/apikey → "Create API key"
  2. Groq (mais rápido): console.groq.com/keys → "Create API Key"
  3. OpenRouter (coringa): openrouter.ai/keys → "Create Key"
